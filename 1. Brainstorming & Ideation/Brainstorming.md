POCKETSMART AI – BRAINSTORMING AND IDEATION

1. Idea Identification

PocketSmart AI is a web-based AI budget planning and recommendation system designed to help users make better spending decisions within a given budget.

2. Problem Identification

Users may find it difficult to plan purchases and activities while staying within a fixed budget. They may need to consider different requirements, preferences, quantities, and available spending limits.

3. Proposed Solution

PocketSmart AI provides a single web-based platform where users can enter their budget and requirements and receive personalized recommendations.

The system focuses on three main areas:

• Home Interior Planning
• Party Planning
• Jewelry Selection

4. AI-Based Approach

The application can use Google Gemini to generate personalized recommendations based on the information entered by the user.

A fallback recommendation system is also included so that recommendations can still be provided when the AI service is unavailable.

5. Main Features Identified

• User registration
• User login and logout
• Dashboard
• Home Interior Budget Planner
• Party Budget Planner
• Jewelry Budget Planner
• AI-generated recommendations
• Budget-based recommendations
• Recommendation history
• Optional outfit image upload for jewelry recommendations
• Fallback recommendations

6. Home Interior Planning

The user can provide a budget, room types, item quantities, and additional requirements. The system generates recommendations according to the available budget.

7. Party Planning

The user can provide a budget, number of guests, event type, venue type, and requirements. The system generates recommendations suitable for the planned party.

8. Jewelry Selection

The user can provide a budget, occasion, style preferences, and optionally an outfit image. The system generates suitable jewelry recommendations.

9. Target Users

The application is intended for users who need assistance with:

• Budget planning
• Home interior purchases
• Party planning
• Jewelry selection
• Personalized recommendations

10. Expected Outcome

The expected outcome is a simple web-based AI application that helps users enter their requirements, receive budget-based recommendations, and view their previous recommendations.

11. Proposed Technologies

• Python
• FastAPI
• Google Gemini
• Jinja2
• HTML
• CSS
• JavaScript
• SQLite
• Pydantic
• Uvicorn

12. Conclusion

The brainstorming phase established PocketSmart AI as an AI-powered budget planning and recommendation system. The idea combines user requirements, budget information, Artificial Intelligence, and recommendation history into one web-based application.
